# konklawe

Lokalne środowisko wieloagentowe: kilku agentów AI (oficjalne CLI dostawców w trybie headless) pracuje równolegle nad projektem, a człowiek obserwuje wszystko na żywo.

Projekt jest w budowie (etap 1, plan w `docs/plan/01-core.md`). Pełny opis instalacji i komend pojawi się na koniec etapu.

```bash
uv sync
uv run konklawe --help
uv run pytest
```
