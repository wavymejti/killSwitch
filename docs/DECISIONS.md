# Decyzje projektowe

| Data | Decyzja | Powód |
|---|---|---|
| 2026-10-05 | Adapter `claude` zawsze podaje prompt przez stdin, nigdy jako argument pozycyjny | `--allowedTools`/`--disallowedTools` to opcje wieloargumentowe, które pochłaniają kolejne argumenty pozycyjne (prompt zostałby wzięty za nazwę narzędzia). Do tego linia poleceń w Windows ma limit ok. 32 tys. znaków. stdin potwierdzony nagraniami |
| 2026-10-05 | Listy narzędzi przekazujemy jako osobne argumenty po jednej fladze (`--allowedTools Read Grep Glob`) | Oba zapisy działają, ale osobne argumenty nie psują nazw ze spacjami, np. `Bash(git log:*)` |
| 2026-10-05 | `permission_mode` akceptuje wartości CLI (`acceptEdits`, `auto`, `manual`, `default`, `dontAsk`, `plan`) z wyjątkiem `bypassPermissions`. Walidacja `extra_args` odrzuca `--dangerously-skip-permissions`, `--allow-dangerously-skip-permissions` i `bypassPermissions` | Zasada 8. `default` nie ma w `--help` (zastąpiło je `manual`), ale CLI 2.1.289 je przyjmuje |
| 2026-10-05 | Nagranie `tool_denied`: `Write` jest niedozwolony (brak w `--allowedTools`), a nie zabroniony (`--disallowedTools`) | Narzędzie zabronione znika z listy, więc model tylko odpowiada, że go nie ma. Narzędzie niedozwolone daje prawdziwą ścieżkę odmowy (`permission_denied`, `tool_result` z `is_error`, `permission_denials`), którą parser musi obsłużyć |
| 2026-10-05 | Nagrania powstają w neutralnym katalogu roboczym (mały `README.md`), a ze środowiska usuwamy `ANTHROPIC_*` oraz zmienne sesji Claude Code | Nagrania mają odzwierciedlać zwykłe uruchomienie agenta, a nie podsesję Claude Code, z którego je zrobiliśmy |
| 2026-10-05 | W fixtures wartości pól `signature` (bloki `thinking`) są zamienione na `REDACTED`. Reszta wyjścia pozostaje bajt w bajt | Sygnatura zawiera zakodowane base64 ID organizacji Anthropic, a fixtures trafiają do repozytorium. Parser sygnatur nie używa |
| 2026-10-05 | Domyślne `strip_env` obejmuje oprócz `ANTHROPIC_API_KEY` i `ANTHROPIC_AUTH_TOKEN` także zmienne sesji Claude Code: `CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT`, `CLAUDE_CODE_SESSION_ID`, `CLAUDE_CODE_CHILD_SESSION`, `CLAUDE_CODE_MESSAGING_SOCKET`, `CLAUDE_CODE_MESSAGING_TOKEN`, `CLAUDE_CODE_SESSION_ATTENDED`, `CLAUDE_CODE_EXECPATH`, `CLAUDE_PID`, `CLAUDE_EFFORT`, `AI_AGENT` | Gdy konklawe działa wewnątrz sesji Claude Code (np. testy uruchamiane przez agenta), dziecko odziedziczyłoby te zmienne i mogło uznać się za podsesję albo łączyć się z gniazdem komunikacyjnym rodzica. Jawna lista zamiast prefiksu `CLAUDE_CODE_*`, żeby nie usuwać celowych ustawień użytkownika |
| 2026-10-05 | Parser `claude` nie emituje zdarzeń (ani `raw`) dla: `system/status`, `system/thinking_tokens`, `system/permission_denied`, bloków `thinking` w `assistant` oraz technicznych `stream_event` (`message_start`, `content_block_start/stop`, delty `thinking`/`signature`/`input_json`, `message_delta`, `message_stop`). Nieznane typy i podtypy dają `raw` | W nagraniach takie linie to ponad połowa strumienia (np. 63 z 138 to `input_json_delta`), a ich treść albo nic nie wnosi, albo jest zdublowana w pełnych wiadomościach i w `result` |
| 2026-10-05 | Wykrywanie limitu opiera się na sygnałach strukturalnych: `rate_limit_event` z `rate_limit_info.status == "rejected"` oraz `assistant` z `error == "rate_limit"`. Dopasowanie tekstu zostaje jako zapas | Oba pola są w schemacie CLI 2.1.289. `overageStatus: "rejected"` występuje także przy zwykłym `allowed`, więc nie może być sygnałem |
| 2026-10-05 | Ruff pomija pliki `*.md` (`extend-exclude`) | Ruff 0.16 formatuje bloki kodu Pythona w Markdownie i przepisałby fragmenty w `docs/plan/01-core.md`. Dokumentacja jest pisana ręcznie |
| 2026-10-06 | Oprócz `load_agents` (rzuca `AgentLoadError`) jest `scan_agents`, które zwraca jednocześnie poprawnych agentów i listę błędów. Obie funkcje przyjmują opcjonalny słownik adapterów (domyślnie rejestr) | `konklawe agents list` ma pokazać poprawnych agentów i błędy zepsutych plików naraz. Wstrzykiwane adaptery pozwalają testować loader bez prawdziwych dostawców |
| 2026-10-06 | Napis z listą narzędzi dzielimy po przecinkach tylko poza nawiasami | Specyfikacje uprawnień Claude mogą zawierać przecinki, np. `Bash(git diff:*, git log:*)` |
| 2026-10-06 | Rejestr adapterów i minimalny `ProviderAdapter` (tylko `validate_agent`) powstały w zadaniu 3. Reszta interfejsu dojdzie w zadaniu 7 | Walidacja agentów wymaga rejestru dostawców, a plan umieszcza adaptery dopiero w zadaniu 7 |
| 2026-10-06 | Kontrakt pola `data` realizują konstruktory `ParsedEvent.<typ>(...)` w `events.py` (pomijają puste pola opcjonalne, skracają podsumowania do 300 i 2000 znaków). Zdarzenie `raw` tworzy `ParsedEvent.unrecognized(...)`, bo `raw` to nazwa pola | Jedno miejsce z kontraktem zamiast słowników składanych osobno w każdym adapterze i w runnerze |
| 2026-10-06 | `rate_limited.resets_at` jest w `data` napisem ISO 8601 w UTC, a nie obiektem `datetime` | `data` pozostaje czystym JSON-em i wygląda tak samo przed zapisem do dziennika i po odczycie |
| 2026-10-06 | `error` może mieć dodatkowe klucze poza `{message, fatal}`, np. `code` z kodem błędu dostawcy | Kod (`model_not_found`, `rate_limit`, …) przydaje się rendererowi i późniejszej obsłudze limitów, a nie mieści się w samym komunikacie |
